# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

A plain HTML + CSS + JS todo list app (lab assignment). No build step, package manager, linter, or tests. To run it, open `index.html` in a browser.

- `index.html` loads `styles.css` and `scripts.js` (with `defer`).
- `assets/` is for static assets (empty right now).

## Conventions

- Keep additions minimal. Add only what the current task asks for.
- Only touch `scripts.js` when a task explicitly asks for scripting.
- Follow `.editorconfig`: LF line endings, UTF-8, final newline, 2-space indent in CSS/JS, 4-space indent in HTML.
